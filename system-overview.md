# House-app - System & product Overview

>version: 1.0.0
> Author: Abdulhakeem Sanni and codex cli
> Last Updated: 20-08-26

## 1. Executive Summary

House-App is Data driven real-estate valuation software which uses historic data to value a property to the current realities of the market. Hence house-app is an AI enable tool used by buyers, sellers and real estate agents and market movers to make informed decision to support there business needs.

## 2. Problem Statement

NorthStar Property partners carry out more than 600 property valuations per month, which can be tedious, tasking and time-expensive, Hence causing inconsitencies across the business branches and affecting operational time of comparing property price values.


## 3. Users 

The AI-powered property valuation system will mostly be used by estate and property agents to produce faster and more consistent property valuations improving efficiency of  operations.

## 4. Core Features

- Predicting / Estimating property Value
- Storing and keeping records of property valuations


## 5. Functional Requirements
- User Registration
- User Authentication and Login
- Property valuation Service
- Property details fill-form
- property details storage - Database
- property valuation History storage - Database
